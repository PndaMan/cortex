## Default Permission

Enables every Cortex iOS bridge command (recorder + widget snapshots).

#### This default permission set includes the following:

- `allow-start-recording`
- `allow-stop-recording`
- `allow-pause-recording`
- `allow-resume-recording`
- `allow-recording-state`
- `allow-read-recording-bytes`
- `allow-list-inbox`
- `allow-delete-recording`
- `allow-set-widget-snapshot`
